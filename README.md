# personal-safety-device-prototype
*An ESP8266-based personal safety device prototype featuring GPS logging, LED strobe alerts and embedded system control.*


This project is a personal safety device prototype developed using an ESP8266 microcontroller, GPS tracking, local data storage, and wireless communication capabilities.

As a Geography student with an interest in spatial data science and location-based technologies, I was particularly interested in exploring GPS tracking systems and how location data can be collected, stored, and transmitted using embedded hardware.

The project was developed during Summer 2026 as an opportunity to learn about embedded systems, electronics prototyping, hardware integration, and microcontroller programming. Working collaboratively with my cousin, I designed and built a prototype that combines GPS tracking, alert functions, and data logging within a compact embedded system. The project allowed me to gain hands-on experience with both hardware and software development while applying concepts related to real-world spatial data collection.
