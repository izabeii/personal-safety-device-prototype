**Personal Safety Device Prototype**
**Overview**

This project is a personal safety device prototype developed using an ESP8266 microcontroller, GPS technologies, embedded electronics, and wireless communication systems.

As a Geography student with a growing interest in spatial data science and location-based technologies, I was particularly interested in understanding how GPS data can be collected, stored, and transmitted using embedded hardware. This project provided an opportunity to explore the hardware side of location data collection before it reaches the stage of analysis and visualisation in GIS and data science applications.

The prototype combines embedded control systems, alert mechanisms, and location-tracking concepts within a single hardware platform. The project was developed as a personal learning project during Summer 2026 and provided practical experience in electronics prototyping, embedded programming, circuit design, and system integration.

**Project Objectives**
Explore embedded systems development using the ESP8266
Investigate GPS-based location tracking concepts
